# JMB TV — official in-page player

JMB TV now restores the channel/player experience using a **small manually approved list of official YouTube live-player embeds**.

The player is YouTube's own embedded player. JMB does not download, restream, proxy, transcode, record or store the broadcast. Availability, ads, region rules and whether an embed is enabled remain controlled by YouTube and the broadcaster.

## Featured in-page player sources

The current featured allowlist is in `tv/app.js`:

- **Asianet News** — official YouTube channel `@asianetnews` (verified broadcaster channel).
- **DD News** — official Prasar Bharati / DD News channel.
- **DD National** — official Doordarshan channel.

The page creates an iframe only from the fixed channel IDs in this allowlist, using the privacy-enhanced YouTube embed host. The directory can show other channel metadata, but a channel is not made playable simply because a third-party playlist contains a URL.

## Why a player may say unavailable

A live player can be unavailable when:
- the broadcaster is not currently live;
- the uploader or YouTube has disabled embedding;
- the video is private, removed, age/region restricted or otherwise unavailable;
- YouTube requires a viewer sign-in or applies another platform restriction;
- the browser or network blocks the YouTube player.

JMB must not try another source, proxy, direct HLS URL, playlist, download or alternate host to get around those restrictions. The **Official source** button opens the broadcaster's own YouTube live page so the visitor can use the original service.

## Adding another channel

Before adding a new channel to the featured list:

1. Confirm the channel is the broadcaster's own official YouTube account (prefer a verified account linked from the broadcaster's official website).
2. Confirm the broadcaster has published a live feed on that account and permits embedding.
3. Record the official YouTube channel ID and canonical source page in the allowlist.
4. Add the source only to `featured` in `tv/app.js`. Do not add raw HLS, M3U8, IPTV playlist or third-party stream URLs.
5. Test the embedded player on the website. If it is blocked, remove/disable that entry; do not try to bypass the block.

For an embed of a particular video rather than a channel live feed, use the embed code generated by the original video owner through YouTube's Share → Embed option and follow YouTube's terms and developer policies.

## Retiring the old proxy

The old Cloudflare media proxy is no longer used by JMB TV. The repository's `cors-proxy-worker.js` has been replaced with a retired Worker that does not relay external media.

GitHub cannot change a Worker already deployed in your Cloudflare account. If the old `jb-proxy` Worker is still deployed, replace it with the current `cors-proxy-worker.js` in Cloudflare Workers & Pages and deploy. The `?ping=1` endpoint should return `"status":"disabled"`, and the old proxy route should return HTTP 410.

The current JMB TV official player does not need a Cloudflare media proxy.
